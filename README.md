# Word by Word

Інтерактивний рідер для вивчення англійської через читання — з перекладом українською.

## Можливості

- 24 оригінальні історії рівнів A1–B2 із кількома абзацами в кожній;
- переклад кожного слова та заголовків за кліком;
- підсвітка слова маркером при наведенні без постійних підкреслень;
- подвійний клік і клік на порожньому місці закривають картку перекладу;
- картка перекладу з’являється поряд з обраним словом;
- особистий лічильник вивчених слів;
- завантаження TXT, MD і FB2 для читання; EPUB позначається на обробку.

## Запуск

Потрібен Node.js 22 або новіший.

```bash
npm install
npm run dev
```

Для перевірки збірки:

```bash
npm run build
```

Для частих і неоднозначних слів використовується вбудований словник. Решта перекладів спершу запитуються через DeepL, а MyMemory використовується як резервний варіант.

## Оформлення статичної версії (папка docs/)

- `index.html` — розмітка сторінки;
- `styles.css` — уся стилістика (палітра з логотипу: сосновий зелений, пісок, корал);
- `app.js` — дані історій, словник і логіка читання, перекладу та власних книжок;
- `fx.js` — візуальні ефекти (живий приклад на початку, стрічка, підсвічування розділу, прогрес читання); без нього сайт працює так само;
- `icons.js` — піктограми для 24 історій;
- `fonts/` — шрифти Onest і Literata, підключені локально, без зовнішніх запитів.

Щоб оновити сайт на GitHub Pages, замініть вміст папки `docs/` цією версією.

### Варіанти оформлення

У папці `docs/` зібрано кілька готових варіантів стилів. Усі працюють з тим самим `index.html`, логіка не змінюється.

- `styles.css` — поточний: світла сторінка, м’який фон лише у трьох секціях (перший екран і власні книжки — блакитний, рідер — другий колір), вписаний між рейками. Межі секцій задають пунктирні рейки по боках і пунктирні розділювачі знизу: вони не доходять до країв екрана, а на перетинах стоять маленькі зірочки (кольори чергуються: синій і бірюзовий). Синій і бірюзовий діляться порівну, кнопки без заливки (лише контур і кольоровий текст), у бібліотеці рівні чергують колір. У читанні наведення підсвічується голубим, вибране слово і картка перекладу — другим кольором. Легка типографіка і тонкі рамки. Другий колір можна перемикати прямо на сайті: кружечки «Другий колір» у шапці, а на телефоні в меню. Вибір запам’ятовується в браузері (`localStorage`, ключ `wbw-second`). Колір за замовчуванням задає атрибут на тегу `<html>` в `index.html`: `data-second="peach"` (персик), `"green"` (зелений) або `"none"` (лише синій); без атрибута — бірюзовий;
- `styles.airy-tinted.css` — попередня версія з кольоровими фонами секцій (блакитний, бірюзовий і білий);
- `styles.airy-rails.css` — версія без жодних фонів (лише рейки, розділювачі й зірочки);
- `styles.airy-rose.css` — попередня версія з рожево-кораловим другим кольором;
- `styles.airy-filled-buttons.css` — версія із залитими кнопками;
- `styles.airy-duo-v1.css` — версія з коралом, де переважав синій;
- `styles.airy-blue.css` — лише синій акцент;
- `styles.airy-palettes.css` — три палітри: синя, `coral` і `mono` (атрибут `data-palette`);
- `styles.airy-emerald.css`, `styles.airy-cream.css` — світлі варіанти зі смарагдовим акцентом і в кремовій палітрі;
- `styles.soft.css` — м’які пастельні тони;
- `styles.sage.css` — шавлієвий зелений на великих полях.

Щоб перемкнути варіант, у `index.html` змініть `href="styles.css"` на потрібний файл.
